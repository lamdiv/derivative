An early native macOS preview of Derivative, with Spaces, per-Space favorites, a floating or fixed sidebar, command search, split view, and pastel themes.

**Apple Silicon · macOS 14 or later.** Intel Macs, Windows, and Linux are not supported by this build.

### Install

1. Download the `.dmg` below, open it, and drag **Derivative** to **Applications**.
2. Open Derivative from Applications. A `.zip` alternative is also available.

**This preview is ad-hoc signed and not notarized by Apple.** macOS may block the first launch. Only open a download you trust; [Apple's instructions](https://support.apple.com/102445) explain the **Privacy & Security → Open Anyway** option. A Gatekeeper-approved release will require Developer ID signing and notarization.

### Before using it

- This is an early development build. Some sign-in, media, and browser interactions still need testing.
- WebM is supported. H.264/AAC, MP4 streaming, and DRM are not enabled; some videos and YouTube livestreams will not play.
- Password management, extensions, sync, private browsing, and automatic updates are not implemented. Check Releases for updates.
- Tabs and organization restore across launches. Unsaved forms, split arrangements, and download history are session-only.

`SHA256SUMS` verifies the downloaded assets. `build-info.json` records the source commit and engine identity. The app includes CEF and Chromium license notices. Please [report issues](https://github.com/lamdiv/derivative/issues) with your macOS version and steps to reproduce.
